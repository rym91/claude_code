# Цепочка: от ключей до опубликованного пина

Три инструмента не дублируют друг друга, у каждого своя зона. Путать их —
основная ошибка: API не умеет annotations, PinInspector не умеет автоматизацию.

## Кто что закрывает

| Данные | Чем брать | Почему не другим |
| --- | --- | --- |
| Annotations (внутренние теги Pinterest) | **PinInspector** | В API v5 их нет — ни эндпоинта, ни поля в схеме пина |
| Точный месячный объём поиска | **PinInspector** | API отдаёт корзину `5M+`, `100K-1M` — сравнить можно, посчитать нет |
| Объём массово и по расписанию | **Ads API** `keywords/metrics` | 25 ключей за запрос, без ручного экспорта; `country_code=US` |
| Соседние и подсказанные запросы | **API** `/terms/related`, `/terms/suggested` | Быстрое расширение сида без открытия десктопа |
| Направление: растёт, сезон, демография | **API** `/trends/keywords/US/top/*` | `pct_growth_wow/mom/yoy` + распределение по полу и возрасту |
| Что реально ранжируется в США | **API** `/search/partner/pins?country_code=US` | Живая выдача; partner-эндпоинт может требовать отдельного одобрения |
| Пробелы конкурентов | **PinInspector** | Показывает annotations, по которым конкурент ранжируется, но не пишет их в тайтл |
| Создание досок, секций, пинов | **API** `POST /boards`, `/sections`, `/pins` | Автоматизация публикации |
| Свои показы, клики, сохранения | **API** `/user_account/analytics`, `/analytics/top_pins` | — |
| **Доля США в трафике** | **GA4 на сайте** | В органической аналитике Pinterest гео-разреза нет |

## Шаги

### 0. Сид
10–15 англоязычных тем из того, что уже есть на сайте. Не больше: сид нужен
широкий по смыслу, а не длинный.

### 1. Расширение
- PinInspector: вытащить annotations из пинов конкурентов по каждой теме,
  плюс annotations по самим поисковым фразам. Экспорт в CSV.
- API: `volume_us.py --expand` — `/terms/related` и `/terms/suggested` по тем же
  сидам, сразу с частотностью.
- Слить оба списка. Пересечение — самое надёжное, разница — зона для проверки.

### 2. Скоринг
Три числа на ключ: объём (PinInspector — точный), рост (`pct_growth_yoy` из
Trends), сезонность (`trend_type=seasonal` — попадает ли пик в ближайшие 2–3
месяца). Отсечь всё, где объём высокий, но выдача забита крупными брендами:
на новом аккаунте это мёртвый вес.

### 3. Кластеризация в доски
Annotations приходят из PinInspector с **category tree** — это готовый скелет,
изобретать структуру не нужно. Правило:

- кластер тянет на доску от **15–20 ключей**, иначе доска не наберёт вес;
- подкластер — это **секция доски** (`POST /boards/{id}/sections`, name ≤180);
- одна доска = один интент. «Вишивка хрестиком» и «Схеми хрестиком» — разные
  доски только если у каждой хватает ключей, иначе это доска и секция.

### 4. Именование досок
Pinterest индексирует название и описание доски — это не витрина, это SEO-поле.

- **name** — головной annotation кластера, дословно, без украшений;
- **description** — 2–3 предложения, 4–6 соседних annotations внутри живого
  текста; в спеке лимита нет, в интерфейсе Pinterest режет на 500.

### 5. Тайтлы и описания пинов
Лимиты API (`POST /pins`): **title ≤ 100, description ≤ 800, alt_text ≤ 500,
link ≤ 2048**. Важно: массовый импорт через CSV режет описание на **500** —
публикация через API даёт лишние 300 символов под ключи. Это единственная
причина предпочесть API вместо CSV.

- **title**: точный annotation в первых словах, дальше уточнение под интент.
  Не «Красиві рушники» — а «Великодній рушник: символіка і як обрати»;
- **description**: первое предложение отвечает на запрос (его видно в выдаче),
  дальше 3–5 соседних annotations естественным текстом, в конце — куда ведём;
- **alt_text**: описание картинки словами, а не повтор тайтла.

### 6. Gap-контроль перед публикацией
PinInspector показывает annotations, по которым конкуренты ранжируются, но
которых нет у них в тайтлах и описаниях. Прогнать свой черновик по этому
списку: то, что там есть, а у нас нет — и есть что дописать.

### 7. Замер и возврат в шаг 3
- `account_report.py` → `top_pins` по `OUTBOUND_CLICK`: какие кластеры дали
  переходы, а не только показы;
- **GA4 по source=pinterest + страна**: единственное место, где видно долю США.
  Без него цикл не замыкается — API этого не отдаёт ни в каком виде;
- кластеры с кликами — доливать пинов; кластеры с показами без кликов — чинить
  тайтл и первое предложение описания, картинка тут ни при чём.

## Где цепочка рвётся

Гео. Всё, что до публикации, можно нацелить на США (`country_code`, `region=US`).
Всё, что после, Pinterest отдаёт без разбивки по странам. Пока на
ridnavyshyvka.com.ua не стоит GA4 с разрезом по стране и источнику, «аналитика
по США» остаётся односторонней: цель ставим, попадание не проверяем.
