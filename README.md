# ¡Hola! — учим испанский

Детское веб-приложение для изучения испанских слов. Русский интерфейс,
96 слов в 9 темах, четыре игровых режима и сохранение прогресса.
Работает без сборки, без зависимостей и без интернета.

## Как запустить

Проще всего — открыть `index.html` двойным щелчком.

Если хочется локального сервера (нужен, например, для стабильной работы
фоновой музыки в некоторых браузерах):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Режимы

| Режим | Что делает |
|---|---|
| 🃏 Карточки | Слово с картинкой, переворот на перевод, озвучка, отметка «выучено» |
| ❓ Викторина | 10 вопросов, выбор из 4 вариантов, направление перевода чередуется |
| 👂 На слух | Слово произносится вслух, нужно выбрать правильную картинку |
| 🧩 Мемори | 6 пар «испанское слово ↔ картинка с переводом» |

За викторину и мемори дают от одной до трёх звёзд, за правильные ответы — очки
опыта. Звёзды, выученные слова и очки видны в шапке и сохраняются между
запусками.

## Темы

Приветствия · Животные · Цвета · Числа · Еда · Семья · Тело · Одежда ·
Транспорт, плюс режим «Всё вперемешку» по всем 96 словам.

## Структура

```
index.html              разметка и подключение скриптов
css/styles.css          оформление, тёмная тема, адаптив
js/data.js              словарь: темы и слова
js/storage.js           прогресс в localStorage
js/sfx.js               звуки через Web Audio + фоновая музыка
js/speech.js            произношение через Web Speech API
js/app.js               экраны, маршрутизация, игровые режимы
assets/audio/           фоновая музыка
```

Новые слова добавляются в `js/data.js` — достаточно дописать объект
`{ es, ru, emoji }` в нужную тему, остальное подхватится само.

## Что нужно от браузера

* Озвучка слов — Web Speech API. Если испанского голоса нет, режим «На слух»
  автоматически скрывается, остальные работают как обычно.
* Прогресс — `localStorage`. В приватном окне приложение работает, но прогресс
  не сохраняется.
* Уважается системная тёмная тема и настройка «уменьшить движение».

## Музыка

`assets/audio/background-music.mp3` — Starostin, «Comedy Cartoon Funny
Background Music». Выключена по умолчанию, включается кнопкой 🎵 в шапке.
Браузеры не дают запустить звук до первого касания страницы, поэтому
музыка стартует после первого клика.
